# Simple Calculator

A beginner-friendly command-line calculator built with Python. It performs basic arithmetic operations and lets the user continue calculating until they choose to stop.

## Features

- Addition, subtraction, multiplication, and division
- Separate functions for each arithmetic operation
- Interactive menu for selecting an operation
- Accepts decimal numbers
- Option to perform multiple calculations in one session
- Handles invalid menu choices

## Technologies Used

- Python
- Functions
- Conditional statements (`if`, `elif`, `else`)
- `while` loops
- User input and formatted output

## Requirements

- Python 3

## How to Run

1. Save the Python script as `simple_calculator.py`.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python simple_calculator.py
   ```

   If your system uses `python3` to launch Python, run `python3 simple_calculator.py` instead.

## Example

```text
Select operation:
1. Add
2. Subtract
3. Multiply
4. Divide
Enter choice (1,2,3,4):
```
